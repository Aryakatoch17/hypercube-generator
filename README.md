# Automated Spectral Isomerism Pipeline for N-Dimensional Hypercubes

## Project Summary

This project demonstrates a mathematically grounded and scalable approach to isomerism validation on high-dimensional hypercube graphs.

Core idea:

1. Build large hypercube structures with sparse matrix algebra.
2. Create structural variations by node permutations.
3. Prove structural equivalence with spectral signatures of normalized Laplacians.
4. Provide an interactive Streamlit frontend for execution logs, metrics, heatmaps, and 3D graph views.

The system is designed to remain practical as graph size grows, where dense adjacency operations become infeasible.

## Mathematical Foundation

For an n-dimensional hypercube:

- Vertices: 2^n
- Edges: n * 2^(n-1)

Each variation is generated by a permutation of node indices, which preserves graph structure by construction.

To validate this efficiently at scale, the pipeline compares sorted eigenvalue signatures from sparse eigensolvers on normalized Laplacians.
Matching signatures across variations provides a strong spectral proof of structural isomerism.

## Key Components

### Large-scale engine

- File: hypercube_agentic/large_scale_pipeline.py
- Responsibilities:
  - Sparse hypercube generation with scipy.sparse
  - Permuted structural variation generation
  - Binned sparse heatmap data generation
  - Spectral signature extraction with eigsh
  - Final isomerism verdict assembly

### Exact graph isomorphism utility

- File: hypercube_agentic/isomorphism.py
- Responsibilities:
  - Exact VF2 check via NetworkX GraphMatcher
  - Returns boolean and optional mapping
  - Used for exact checks on manageable graph sizes or sampled views

### 3D projection and visualization helpers

- Files:
  - hypercube_agentic/projection.py
  - hypercube_agentic/visualization.py
- Responsibilities:
  - Deterministic nD to 3D projection
  - PCA-based 3D embeddings for visual interpretation
  - Plotly-ready node/edge rendering workflows

### Interactive web frontend

- File: app.py
- Responsibilities:
  - Streamlit UI with wide layout and professional controls
  - Real-time agentic execution status
  - Scale metrics (vertices and edges)
  - Side-by-side heatmaps for variations
  - Isomer pair visualization
  - PCA-to-3D graph view
  - Actual bit-geometry 3D projection view
  - Final spectral verdict with eigensolver timing
  - Graceful error handling for memory pressure

## Current Pipeline Flow

1. Process 1: Generate sparse adjacency matrices.
2. Process 2: Apply permutations and compute variation heatmaps.
3. Process 3: Run sparse eigensolver and compare signatures.
4. Display verdict, timing, and interactive visual evidence.

## Performance and Scalability Notes

- Sparse construction avoids dense adjacency blowups.
- Spectral checks are significantly faster than full exact isomorphism on large graphs.
- The UI uses sampled graph views for interactive 3D rendering at high n.
- Exact VF2 checks are retained for small graphs and sampled validation contexts.

## Practical Limits

- The backend accepts large n, but practical limits depend on available RAM and CPU.
- Frontend includes MemoryError-safe handling and user feedback for oversized runs.
